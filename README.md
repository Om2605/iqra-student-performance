# Student Performance Review (ระบบติดตามผลการเรียน)

Frontend redirect wrapper to bypass in-app browser restrictions (LINE, Facebook, Instagram) and smoothly launch the Google Apps Script web application for Iqra Muslim School.

## Links

- **Live GitHub Pages URL:** `https://om2605.github.io/iqra-student-performance/` *(or your chosen repository name)*
- **Backend Google Apps Script:** [Student Performance Review Executable](https://script.google.com/a/macros/iqra.ac.th/s/AKfycbwsQk5-nTeq5p27-4A7dyjMxppl08vnq3exx_ygRnOeXvmX6mAQXxruHGdTSq99d1zoWQ/exec)

## Setup on GitHub Pages

1. Create a repository on GitHub (e.g. `iqra-student-performance` or `iqra-performance-review`).
2. Push `index.html`, `logo.png`, and `README.md`.
3. Go to **Settings** > **Pages**.
4. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
5. Your live link will be ready at: `https://om2605.github.io/<repository-name>/`.
